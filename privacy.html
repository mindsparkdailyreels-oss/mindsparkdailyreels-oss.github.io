Privacy Policy

Last updated: October 11, 2026

This policy explains how reel-bot, the tool used by Mind Spark Daily, handles data. reel-bot is used only by Mind Spark Daily to publish videos to its own YouTube channel. It is not offered to the public and does not collect data from viewers.

YouTube API Services

reel-bot uses the YouTube API Services. By using reel-bot you are agreeing to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data reel-bot accesses

  • Channel details (channel name and ID) of the signed-in Mind Spark Daily account, to confirm which channel videos are uploaded to.
  • Upload access, to publish Shorts that reel-bot has prepared.

reel-bot does not access viewers' personal information, comments, subscribers, watch history or any other user's account.

How data is stored and shared

The sign-in token and a record of uploaded videos (video ID, link and upload time) are stored only on the Mind Spark Daily owner's own computer. This data is not sold, shared with third parties or used for advertising. It is kept only as long as reel-bot is in use and is deleted when reel-bot is removed.

Revoking access

Access can be revoked at any time from the Google security settings page.
